# Getting started

Type what you want in plain English (or Hinglish) into the bar at the top of
the dashboard — or press **Ctrl+Alt+Space** from inside any app for the quick
input box.

Some things to try:

- `open chrome` · `close spotify`
- `set volume 40` · `mute` · `set brightness` (uses your default level)
- `take screenshot`
- `remind me to stretch at 4pm`
- `create study mode chrome and youtube.com` then `activate study mode`
- `undo` — reverses your last action where possible

**Everything runs and stays on this machine.** Nothing you type or say ever
leaves it unless you explicitly send an issue report.

Destructive actions (shutdown, delete mode, empty recycle bin…) always show a
quiet confirmation card first — never an alarm, never a sound.
