Good to know

Questions

Is it really free?

Yes — completely, with every feature unlocked and no time limit. There’s no paid tier, no license key, and nothing to activate. Download it and it just works.

Does Isha send my data anywhere?

No. It runs entirely on your PC and makes no network request unless you explicitly ask it to — for example, to check for an update. There’s no analytics or telemetry of any kind. Read our privacy policy and threat model for the details.

Which Windows versions are supported?

Windows 10 and Windows 11 (64-bit). Isha is a lightweight app — a calm main window that tucks into your system tray, using only tens of megabytes of RAM.

How do I install it?

Download the latest release, unzip it, and run Isha.exe — no installer account or key needed. Because the build isn’t code-signed yet, Windows SmartScreen may show a warning the first time; click “More info” → “Run anyway”.

What can it actually do?

Open and close apps, control volume and brightness, manage windows, run Modes, set reminders, expand snippets, take screenshots, and much more — by typing, a hotkey, or voice. See the full list on How it works.

Do I need an internet connection?

No. Isha is fully local and works entirely offline. The only time it touches the network is when you explicitly ask it to check for an update or send an issue report you’ve reviewed.
