How Isha works

Everything below is real and already in the app — nothing here is a roadmap promise.

Isha is one command brain reachable three ways — type it, press a hotkey, or say it — and it turns plain English (or Hinglish) into an action on your Windows PC. There's no cloud step: parsing, matching, and execution all happen locally.

The three ways in

  • Command palette — a Spotlight-style box on a global hotkey (default configurable in Settings). Press it, type, hit enter.
  • Custom command hotkeys — bind any keyboard shortcut directly to any command text (e.g. Ctrl+Alt+S → take screenshot). It fires instantly, no palette needed — set these up in Settings → Hotkeys.
  • Voice — an optional offline speech module. Press the voice hotkey, speak, Isha transcribes on-device and runs it like typed text. No audio ever leaves your machine.

All three funnel into the exact same pipeline, so a command behaves identically no matter how you triggered it.

Understanding what you type

Isha tokenizes your sentence, strips filler words ("please", "the", "a"), and matches the remaining words against a verb map and a target map — so "open chrome", "launch chrome for me", and "chrome kholo" (Hinglish) can all resolve to the same action. You can also teach it your own words: aliases (Settings → Aliases) let you map any nickname to an app, URL, or mode — "my email" → gmail.com, for instance.

Modes — one word, a whole workspace

A Mode bundles apps, websites, a volume level, and even a desktop theme under one name. Say "create study mode chrome, notion and youtube.com", then just say "study mode" to open everything at once, and "study mode off" (or its Hinglish equivalent) to close it all back down. Modes can also capture your current window layout and restore it later.

Auto-triggers

Modes can switch automatically — by time of day, or on an event like unplugging the charger — configured in config.json, checked by a background scheduler. Set it once and it just happens.

Safety: confirm & undo

Anything hard to reverse (uninstalling an app, emptying the recycle bin, running a mode's custom script) asks for confirmation first — Isha never silently does something destructive on your behalf, including when a command fires from an unattended hotkey or scheduled trigger. Made a mistake anyway? Say "undo" and Isha reverts the last reversible action it took.

Dashboard & Settings

The Dashboard (tray icon → Dashboard, or the palette's Dashboard button) is your at-a-glance home: which Mode is active, your most recent commands, your license status, and one-click quick actions (screenshot, disk space, empty recycle bin, and more). Settings is where you configure everything: aliases, hotkeys, licensing, and general preferences.

Full command list

Every action below works from the palette, a bound hotkey, or voice. Bold entries are included free in Isha Lite; everything else needs a full Isha license.

Apps & system

  • Open / close any installed app — "open chrome", "close spotify"
  • Volume — set, increase, decrease, mute, unmute — "volume 30", "mute", "turn sound up"
  • Brightness — set, increase, decrease — "brightness 70", "screen down a bit"
  • Other system toggles — Wi-Fi, Bluetooth, airplane mode, do-not-disturb, night light, dark/light mode
  • Power actions — shut down, restart, sleep, hibernate, lock screen

Windows & workspace

  • Focus, maximize, minimize, show, or hide any window by app name
  • Snap, resize, or move a window to a screen position — "snap chrome to the left"
  • Modes — create, activate, deactivate, update, delete; per-mode volume, theme, script, and captured window layout

Web & search

  • Open any URL or alias — "open my email"
  • Web search — "search best pizza near me"

Productivity

  • Reminders and scheduled tasks — "remind me to stretch in 20 minutes"
  • Task list — add / cancel tasks
  • Copy or rename a file, uninstall an app
  • Clipboard history — view or clear it
  • Text snippet expansion
  • Pomodoro timer — start and stop

Utilities

  • Take a screenshot
  • Check disk space
  • Check internet connectivity
  • Empty the recycle bin
  • Undo the last reversible action
